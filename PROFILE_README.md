## What I'm building

| Project | What it does | Stack |
| --- | --- | --- |
| **[Strata](https://strata-weld-sigma.vercel.app)** | Tracks startups by sector from public data, classifies them with Gemini under human review, and writes briefs where every claim cites a source. 465 companies, 136 SEC Form D filings verified, 87.8% classifier accuracy on hand-labelled data. | Node, Express, MongoDB, Next.js, Kafka, Redis, Gemini |
| **[HiveState](https://hive-state.vercel.app)** | Draw a workflow of AI agents, run it, and keep cost under control. Parallel DAG runner, daily budget guard, human-in-the-loop pause and resume. | Next.js 16, React 19, Supabase, React Flow, Gemini, OpenAI |
| **Tally** | Payments reconciliation across ledger, processor and bank, graded against a hidden answer key. 0.999 precision, 0.994 recall, 1M rows in ~7s, plain-English questions turned into validated read-only SQL. | Python, DuckDB, dbt, FastAPI, Next.js, Airflow |
| **Citable** | Audits how a site shows up for search engines and AI assistants, then proposes and applies fixes. | Next.js, Prisma, Node worker, Claude API, Stripe |
| **[Sealcloak](https://www.sealcloak.com)** | Marketing site for an offline Android vault, in 11 languages including right-to-left Arabic. | Custom Node static build, Vercel |
| **[Honest Mailbox](https://www.honestmailbox.com)** | A private space for couples, with end-to-end encrypted chat and tested Firestore rules. | Next.js, Firebase, Firestore |
